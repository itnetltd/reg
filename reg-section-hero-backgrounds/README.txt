REG Drupal section hero background pack

-----
about-reg.png          -> About REG default
what-we-do.png         -> What We Do / operations default

public-information.png -> Public Information / tenders / jobs / publications

Implementation rule
-------------------
These files are only default/fallback assets. Drupal editors must be able to replace each section hero through Drupal Media Library without editing Twig/CSS.
