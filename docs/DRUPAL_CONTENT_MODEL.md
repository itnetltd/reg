# Recommended Drupal Content Model

## Content types

### News

- Title
- Summary
- Body
- Featured image
- News category
- Publication date
- Featured checkbox

### Tender

- Title
- Summary
- Reference number
- Status
- Opening date
- Closing date
- Tender document
- External application URL

### Outage update

- Title
- Description
- Outage type: current or planned
- District
- Sector
- Start date/time
- Expected restoration date/time
- Status
- Map coordinates

### Video

- Title
- Video URL or media entity
- Thumbnail
- Source/author
- Featured checkbox

## Reusable paragraph/block types

- Hero
- Quick service
- Impact metric
- Partner logo
- Call to action

## Taxonomies

- News category
- District
- Sector
- Tender status
- Outage status

## Views

- Homepage news: two latest featured items
- Current outages: three latest active outages
- Planned maintenance: three upcoming items
- Active tenders: three latest active tenders
- Featured videos carousel
